# PixAI 공식 API 대기열

**0.10.0.** 기존 조합·대기열에 공통문 세트, 프리셋 자체 문구, 씬·출연·캐릭터×씬 일괄 예약, 이미지 생성 정보 읽기를 추가했습니다. 공식 API로 생성·조회하고 이미지를 저장하며, 별도 JSON 파일은 자동 생성하지 않습니다. PNG 요청 정보 기록은 선택 사항으로 기본 꺼짐입니다. PixAI와 제휴하지 않은 개인 도구이며, 공식 API 사용 조건과 서비스 약관이 적용됩니다. 공개 설치 링크는 GitHub에 게시된 버전을 제공합니다.

**처음 사용하시나요?** [버튼을 따라가는 사용 설명서](GUIDE.md) · [스크립트 설치·업데이트](https://raw.githubusercontent.com/cotton100/pixai-web-queue/main/pixai-web-queue.user.js)

흐름: **설정에서 API 키·저장 위치 준비 → 라이브러리에 재료 저장 → 조합 예약 → 대기열 등록 → 첫 작업만 실행 → 저장·기록 확인**. 예약과 등록 단계에서는 생성 요청을 보내지 않습니다. API 생성에는 크레딧이 사용됩니다.

## 처음 사용

[기존 설치/업데이트 주소](https://raw.githubusercontent.com/cotton100/pixai-web-queue/main/pixai-web-queue.user.js). GitHub 반영 여부를 확인하고 업데이트합니다. 스크립트 이름·namespace는 유지했으므로 기존 항목을 업데이트하고 같은 스크립트 두 개를 동시에 켜지 않습니다. 최신 Tampermonkey의 PixAI API/이미지 도메인 접근 권한이 필요합니다.

1. 설치한 버전과 패널 제목을 확인합니다. **조합 예약 → 프리셋·캐릭터 선택 바로 아래**에서 비율·크기·생성 모드·생성당 이미지 수를 고릅니다.
2. 설정 → 공식 API 키 → **이 탭에 키 연결**. 입력란을 즉시 비우며 기본값은 탭 메모리 보관입니다. 기본 모드에서는 새로고침하면 다시 입력합니다. 필요하면 **이 브라우저에 API 키 기억하기 (선택)**를 체크한 뒤 연결합니다. 이 도구의 설정·대기열 백업에는 키를 넣지 않습니다.
3. **기존 작업으로 연결 확인**은 조회만 합니다. ID 입력이 비어 있으면 대기열의 첫 기존 ID를 사용합니다. 키 입력과 인증 성공은 구분합니다.
4. 저장 위치를 준비합니다. Chrome/Edge는 폴더 선택·쓰기 권한, Firefox는 Tampermonkey Browser API 다운로드 설정·준비 확인이 필요합니다. Firefox 저장 위치는 브라우저 다운로드 설정을 따릅니다.
5. 모델/LoRA는 조합 프리셋으로 지정합니다. 통짜 작업은 기본 모델 **버전** ID를 입력할 수 있고, 비어 있으면 첫 실행에서 사이트 모델/LoRA·네거티브를 읽습니다. 모델 페이지 ID와 버전 ID는 다릅니다.
6. **조합 예약의 프리셋·캐릭터 선택 아래**에서 비율·크기, **모델 기본값 / Lite / Standard / Pro / Ultra**, **1장 / 4장 배치**를 고릅니다. 스타일·시드와 미리 등록할 작업 수(1~10개)는 **설정**에서 정합니다. 사이트 해상도·스타일·참조 설정은 복사하지 않습니다. 모드는 **모델 기본값 (모드 보내지 않음)**을 권장합니다. Tsubaki.3에 `standard`를 보내면 서버가 inferenceProfile을 인식하지 못해422로 거절한 실측이 있습니다. 다른 모드의 실호환성은 미검증입니다. 새 예약과 대기열 등록 시 API 옵션·배치 수를 각각 보관합니다.
7. 생성은 크레딧을 사용합니다. **기존 사이트 비용 상한은 API에 적용할 수 없습니다.** 설정의 안내를 확인하고 **첫 작업만 실행**으로 한 장부터 시험합니다. 첫 미완료 작업이 대기이면 새 생성이고, ID가 있으면 조회·저장만 재개합니다.

## 키 기억하기와 삭제

기억하기는 Tampermonkey의 **이 스크립트 저장소**에 키를 저장합니다. PixAI 사이트 localStorage에는 저장하지 않습니다. 다음 방문에는 저장된 키를 메모리로 불러오며 입력칸은 비워 둡니다. 자동으로 생성하거나 연결 확인 요청을 보내지 않습니다. 지원하지 않는 스크립트 관리자는 저장 없이 연결만 가능합니다.

체크만 하면 저장하지 않으며 **이 탭에 키 연결**을 눌러야 저장됩니다. 체크를 끄면 저장된 사본을 지우고 현재 탭의 메모리 연결은 유지합니다. **키 지우기**는 저장된 사본과 현재 탭의 연결을 지웁니다. 이미 열린 다른 탭의 연결은 각 탭에서 지워야 합니다.

암호화 금고가 아닙니다. 확장 관리자 백업·동기화에는 키가 포함될 수 있고, 기기·확장 관리자에 접근할 수 있는 사람으로부터 키를 보호한다고 보장하지 않습니다. 공용 PC에서는 저장하지 않는 것을 권장합니다. 저장하지 않는 방식도 사용 중인 페이지 입력란·메모리까지 안전을 보장하는 것은 아닙니다. 업데이트 시 스크립트 저장소 권한 추가 안내가 나올 수 있습니다.

## 대기열 정리

- **진행 대기열**에는 아직 완료하지 않은 작업을 표시합니다. 저장이 끝나면 **완료·보관 기록**으로 자동 이동합니다.
- 작업 제목 왼쪽에서 선택한 뒤 **선택 삭제**, 또는 **현재 목록 전체 삭제**를 사용합니다. 현재 탭에 표시한 목록만 대상이며 건수 확인 후 적용됩니다. 삭제한 기록은 복구할 수 없으므로 필요하면 대기열 백업을 먼저 받습니다. 이미지 파일·프리셋·청크는 삭제하지 않습니다.
- **새 대기열**은 미제출 작업을 기록으로 보관하고 진행 목록을 비웁니다. 기록의 **건너뛰기 취소**로 다시 가져올 수 있습니다. 새 작업 등록은 기존 조합 화면에서 합니다.
- 실행 중에는 정리할 수 없습니다. 이미 제출했거나 제출 결과가 불명확한 미완료 작업은 삭제·새 대기열 대상에서 보호합니다. 전체 삭제가 막히면 안전한 항목만 선택 삭제하거나, 보호된 작업을 같은 ID로 재개해 저장을 마칩니다.

## 보존·복구와 제한

받은 작업 ID는 유지합니다. 재개할 때 기존 ID부터 처리하고, 제출 응답 유실·시간 초과·판단 불가 5xx는 자동 재전송하지 않습니다. 저장 실패는 같은 ID의 다운로드·저장만 재개합니다. 기존 파일을 덮어쓰지 않습니다. 중지는 새 제출을 멈추며 서버 작업을 취소하지 않습니다. 활성 작업 조회 간격은 5초이며 웹훅은 사용하지 않습니다.

API 옵션은 설정 백업에, 확정 요청과 저장 이력은 브라우저 대기열과 수동 대기열 백업에 포함합니다. 세션 키와 별도로 기억한 API 키는 이 도구의 백업에서 제외합니다. 0.9.5부터 이미지 옆 JSON 자동 저장은 제거했습니다. 기존 JSON 파일을 삭제하지 않으며 설정/대기열 백업 버튼은 유지합니다. 공식 응답에 프롬프트가 없으면 ID·생성 시각만 검증하며, 로컬 요청 사본을 서버 확인 정보로 표시하지 않습니다.

설정 변경은 이미 확정된 대기 요청에 자동 반영되지 않습니다. 미제출 대기 작업의 **현재 API 옵션 적용**을 누르면 해당 작업만 다시 확정합니다. 이전 요청은 `apiRequestHistory`에 보존하며 프롬프트·모델/LoRA·조합·기존 랜덤 시드는 유지합니다. 작업 ID가 있거나 제출 결과가 불명확하거나 저장된 출력이 있으면 요청을 바꾸지 않습니다. 버튼은 새 생성을 실행하지 않습니다.

비율은 **가로:세로**입니다. **5:3은 가로**, **3:5는 세로**입니다. 대기열 카드에 실제 적용할 비율·크기가 표시되며 현재 선택과 다르면 안내합니다. 비율·크기 선택 아래의 **기존 대기 작업의 비율·크기 변경**을 펼친 뒤 **미제출 대기 작업에 비율·크기 적용**을 누르면 변경 가능한 대기 작업만 한 번에 갱신합니다. 기존 모델/LoRA·프롬프트·모드·시드·배치 수와 이전 요청 사본을 보존합니다. 이미 제출한 작업·완료 작업·제출 결과가 불명확한 작업은 대상에서 제외합니다.

조합 예약의 **프리셋·캐릭터 선택 바로 아래**에 **비율·크기·생성 모드·생성당 이미지 수** 버튼 목록이 있습니다. 좁은 화면에서는 **재료** 탭에서 고릅니다. 새 예약은 화면에서 고른 네 값을 각각 보관합니다. 예를 들어 가로 5:3·Pro·4장 예약과 세로 3:5·Ultra·1장 예약을 함께 등록할 수 있습니다. 선택값은 최근 조합·즐겨찾기·설정 백업에도 보존되며, 같은 재료라도 이미지 설정이 다르면 별도 조합으로 기록합니다. 이전 예약에 없는 옵션은 대기열 등록 시점의 선택값을 적용합니다. 이미 등록한 작업은 선택 변경만으로 바뀌지 않습니다. **현재 API 옵션 적용**은 모드·배치 수도 갱신하고, **미제출 대기 작업에 비율·크기 적용**은 모드·배치 수를 유지하므로 적용 대상을 확인하세요.

청크와 캐릭터는 각각 폴더로 묶습니다. **이름 있는 폴더는 처음에 접혀 있고**, 미분류 목록은 펼쳐 있습니다. 같은 화면에서 직접 펼친 상태는 항목 저장·검색 후에도 유지합니다. 폴더 제목을 눌러 펼치고 항목을 누르면 그 자리에서 편집합니다. 폴더·항목의 ⠿ 손잡이로 순서와 소속 폴더를 바꾸고, 체크한 여러 항목을 이동·복제·삭제할 수 있습니다. 이동 대상에서 새 폴더도 바로 만들 수 있습니다. 폴더만 삭제하면 안의 항목은 미분류로 이동하고 프롬프트와 기존 예약은 유지됩니다. 캐릭터 폴더도 설정 백업에 포함됩니다. 최신 백업은 0.9.14 이상에서 불러오세요.

조합창의 프리셋·캐릭터·청크 선택과 순서·LoRA 트리거 위치·횟수·이미지 설정을 이 브라우저에 기억합니다. 과금 안내 체크도 체크/해제한 상태를 로컬에 보관합니다. 새로고침 시 편집 상태만 복원하며 자동으로 예약·등록·생성하지 않습니다. 과금 안내 체크와 현재 편집 상태는 설정 백업에 넣지 않습니다. 저장 실패는 화면에 알리며, 비율·크기 저장 실패는 선택값을 되돌립니다. 빈 횟수 입력은 마지막 유효 편집 상태를 덮어쓰지 않습니다. 설정 파일을 명시적으로 가져오면 편집 상태는 가져온 라이브러리에 맞춰 초기화합니다.

LoRA는 **최대 5개·수치 0~1·LoRA 버전 ID**가 필요합니다. 기존 음수/1 초과 수치를 임의로 바꾸지 않고 제출 전에 멈춥니다. 프리셋에서 고친 뒤 새 예약을 만듭니다. 조합에 넣은 트리거는 사용자 순서를 유지하고 API 자동 추가를 빈 사용자 트리거로 덮어쓰도록 구현했습니다. 실제 T3에서 중복 억제·위치 보존은 미검증입니다. 통짜 작업에 트리거 정보가 없으면 API 기본 트리거를 사용합니다.

Tsubaki.3(버전2024383379556065549)·LoRA 3개(0.8/0.5/0.5)·4장 배치 2건 생성과 원본8장·JSON2개 자동 저장을 Chrome에서 확인했습니다. 테스트 전후 잔액은14,000크레딧 감소했습니다. 이 값은 해당 설정의 관측값이며 다른 모델·모드·크기에 대한 가격 보장이 아닙니다. Firefox 동작은 미검증입니다. Reference Pro·Edit·Edit Lite·영상은 API 미지원입니다. 자동 비용 상한·잔액·환불을 약속하지 않습니다.

## 검증·관련 자료

0.10.0은 아래 기능을 추가합니다. 빌드 동기화·구문·전체 **430/430** 검사가 통과했습니다. 검증은 합성 이미지·모의 DOM·가짜 API 응답을 사용하며 사용자 이미지·키·유료 API는 사용하지 않습니다. Chrome 154의 합성 자료 페이지에서 브라우저 PNG 파서·압축·요청 기록·Bitmap 8×8을 확인했습니다. 실제 Tampermonkey 설치 UI·파일 선택/드롭·다운로드·폴더 저장과 새 화면의 1440×900/640×800 검증은 아직 수행하지 않았습니다. Firefox 제어는 도구의 URL 정책 지원 문제로 중단되어 실검증하지 못했습니다. 배포 전 독립 코드 리뷰(gpt-6-astra)의 설정 보존 P2를 수정하고 전체 회귀를 다시 통과했습니다.

- **공통문**: 이름 있는 세트가 기본 공통문을 대체하고 프리셋 자체 포지·네거를 더합니다. 예약할 때 문구를 고정합니다. 트리거 `맨 끝`은 씬 문구 뒤입니다.
- **씬·출연**: 청크 사본을 씬으로 저장·편집·복제하고 그룹으로 이동합니다. 원본 갱신은 변경 내용을 확인한 뒤 적용합니다. 캐릭터 기본 프리셋과 복장 등 출연 변형을 관리합니다.
- **일괄 예약**: 행/열 순서, 공통 반복, 쌍별 예외(0=제외), 씬별 이미지 옵션, 저장한 구성과 묶음 필터를 제공합니다. `3×3×2×4장 = 18작업·72장`. 바로 등록도 생성 버튼을 누르지는 않습니다. 실행 중인 대기열에 등록하면 기존 실행 정책에 따라 이어서 처리됩니다.

- **백업**: 새 전체 백업 v2, 앱 0.1.11 호환 v1, 구형 스크립트 0.9.14 호환 v1을 구분합니다. 구형 형식의 제외 내역을 저장 전에 표시하고 예약 문구는 합쳐 보존합니다. 앱의 **앱용 백업**을 가져오세요. 앱의 기존 **스크립트용 내보내기**에서 이미 빠진 씬 등의 데이터는 복원할 수 없습니다.
