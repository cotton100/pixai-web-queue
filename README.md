# PixAI 웹 대기열

로그인된 [PixAI 한국어 새 이미지 에디터](https://pixai.art/ko/generator/image)에서 **모델·LoRA 트리거 프리셋 + 캐릭터 + 여러 프롬프트 청크**를 조합해 순차 생성하고, 원본 이미지 전부와 JSON 기록을 저장하는 Tampermonkey 유저스크립트입니다.

현재 **0.3.2 후보**입니다. 설정 JSON 내보내기·불러오기와 적용 전 설정 복구를 추가했습니다. 문법·모의 테스트와 로컬 Chrome에서 파일 선택·미리보기·설정 교체·복구를 검증했습니다. 실제 Firefox/Tampermonkey에서 이 버전의 설정 파일 저장과 불러오기, PixAI 자동 설정/제출·원본 다운로드·크레딧 차감은 미검증입니다. 이미지 생성은 실행하지 않았습니다.

## 설치 · 업데이트

[유저스크립트 설치 / 최신판으로 업데이트](https://raw.githubusercontent.com/cotton100/pixai-web-queue/main/pixai-web-queue.user.js)

1. 최신 Tampermonkey에서 위 링크로 기존 항목을 업데이트합니다. 스크립트 이름·namespace는 유지했습니다. 같은 스크립트 두 개를 동시에 켜지 마세요.
2. PixAI 탭을 새로고침하고 제목의 **0.3.2 후보**를 확인합니다.
3. 자동 업데이트 확인을 켜두면 GitHub의 새 버전을 주기적으로 확인합니다. 즉시 반영하려면 업데이트 확인 후 PixAI 탭을 새로고침합니다.

기존 대기열·저장 방식·패널 위치는 유지됩니다. 제목줄을 드래그하면 패널이 이동하고 위치를 기억합니다. 제목 오른쪽 **접기 아이콘**을 누르면 52px 이미지 아이콘만 남고, 다시 누르면 펼쳐집니다. 접힘 상태도 기억합니다. 접기/열기는 입력 중인 내용과 실행 중인 대기열을 유지합니다. 위치를 바꾸려면 펼친 뒤 제목줄을 드래그합니다.

0.3.0에서는 **씬 → 청크**로 이름을 바꾸고 예약 목록에서 여러 청크를 체크할 수 있습니다. 기존 씬과 단일 씬 예약은 청크로 불러옵니다. LoRA별 트리거 키워드도 프리셋과 함께 저장합니다. 이미 대기열에 등록된 작업의 프롬프트와 설정은 바뀌지 않습니다.

상태는 제목 아래와 누른 버튼 바로 아래에 표시합니다. **사이트의 현재 설정 읽기**는 대기열 오류와 독립적으로 동작합니다. 숨겨진 화면·행은 제외하고 같은 모델/버전의 중복 링크는 하나로 처리합니다. 서로 다른 모델이 보이면 오류를 표시합니다.

## 조합 예약 사용법

먼저 아래 저장 준비를 완료합니다. 각 편집 영역은 제목을 눌러 펼칩니다.

1. **① 공통 프롬프트:** 모든 조합에 넣을 화풍·품질 등과 공통 네거티브를 입력하고 **공통문 저장**을 누릅니다.
2. **② 모델 · LoRA 프리셋:** PixAI 화면에서 원하는 모델·버전·LoRA를 선택한 뒤 **사이트의 현재 설정 읽기**를 누릅니다. 각 LoRA의 공개 상세 페이지에 등록된 **Trigger Words**를 자동으로 채웁니다. 내용을 확인하고 이름을 붙여 **프리셋 저장**을 누릅니다. 같은 LoRA·버전에 직접 입력한 문구가 있으면 유지하고, 빈칸에는 조회값을 넣습니다. 직접 수정하거나 지운 뒤 저장할 수도 있습니다. 공개되지 않았거나 읽지 못한 트리거는 해당 LoRA 이름과 안내를 표시하므로 직접 입력해 주세요. 모델·LoRA 설정 읽기는 그대로 사용할 수 있습니다. ID는 함께 읽어오며 필요할 때만 직접 편집 영역을 펼칩니다.
3. **③ 캐릭터 프롬프트:** 이름·외모·의상·고유 특징과 캐릭터 네거티브를 따로 저장합니다.
4. **④ 프롬프트 청크:** `smile`, `waving`, `indoor`처럼 표정·행동·구도·배경을 재사용할 프롬프트 조각으로 저장합니다. 청크별 네거티브도 저장할 수 있습니다.
5. **⑤ 조합 예약:** 설정 프리셋·캐릭터를 고르고 **함께 쓸 청크** 목록에서 원하는 항목들을 체크합니다. 선택한 청크는 목록 순서대로 한 프롬프트에 합쳐지고, 아래 미리보기가 바로 갱신됩니다. 생성 횟수를 입력하고 **이 조합 예약 추가**를 누릅니다. 청크를 선택하지 않아도 예약할 수 있습니다.
6. 크레딧 상한을 확인하고 **예약 전부를 대기열에 등록**을 누릅니다. 성공하면 예약 목록은 비워지고 작업별 설정과 프롬프트가 복사됩니다. 프리셋을 나중에 수정하거나 삭제해도 이미 등록된 작업은 유지됩니다.
7. **시작 / 같은 작업 재개**를 누릅니다. 각 작업의 모델·LoRA·수치를 화면에 적용하고 프롬프트와 설정이 일치하는지 확인한 뒤 제출합니다.

합치는 순서는 **공통문 → LoRA 목록 순서의 트리거 → 캐릭터 → 선택한 청크 목록 순서**입니다. 예: 공통 `masterpiece` + 트리거 `character_name` + 캐릭터 `1girl, silver hair` + 청크 `smile`, `waving` → `masterpiece, character_name, 1girl, silver hair, smile, waving`. 네거티브는 공통문 → 캐릭터 → 선택 청크 순서로 합칩니다. 태그 중복·줄바꿈·가중치 문법을 임의로 바꾸지 않습니다. 청크3개를 선택하고2회를 예약하면 세 청크를 함께 넣은 작업2개가 생깁니다.

**화면에 설정 적용 · 생성 안 함**으로 모델·LoRA 프리셋만 먼저 확인할 수 있습니다. 읽어오기·설정 적용·대기열 등록 자체는 이미지를 생성하지 않습니다. 삭제된 항목을 참조하는 예약은 표시되며, 해당 예약을 제외하거나 새 조합으로 다시 추가해야 등록할 수 있습니다.

기존 방식은 **통짜 프롬프트 · 간단 대기열**에 있습니다. 여러 프롬프트를 독립된 한 줄 `---`로 나누고 반복 횟수를 정합니다. 통짜 작업만 실행할 때는 시작 시 화면 설정을 사용합니다. 프리셋 작업과 섞이면 첫 시작의 모델·LoRA·네거티브를 통짜 작업에도 저장해 중지·새로고침 이후 설정이 바뀌지 않도록 합니다.

생성 횟수는 사이트 생성 버튼을 누르는 횟수입니다. 사이트가 4장 묶음이면 2회 예약은 총8장을 생성합니다. 작업은 최대1,000개, 조합당1~100회입니다. 크레딧 상한 기본값은7,800, 빈칸은 제한 없음입니다. 비용을 읽지 못하거나 상한을 넘으면 제출하지 않습니다.

## 설정 내보내기 · 불러오기

패널 아래 **설정 내보내기 · 불러오기**를 펼칩니다. 생성 이미지 저장 폴더를 먼저 선택하지 않아도 이용할 수 있습니다.

- **설정 내보내기:** 저장한 공통문·네거티브, 모델/LoRA/수치/트리거 프리셋, 캐릭터, 청크, 조합 예약과 현재 크레딧 상한·파일 이름·반복 횟수를 JSON으로 다운로드합니다. 편집 중인 항목은 먼저 해당 저장 버튼으로 저장하세요.
- **설정 불러오기:** JSON 파일을 선택하면 항목 수와 기본 옵션을 보여줍니다. 아직 기존 설정은 바뀌지 않습니다. **이 설정으로 교체**를 눌러 적용하거나 **불러오기 취소**를 누릅니다. 적용하면 저장한 설정과 편집 중인 프리셋/캐릭터/청크 내용이 가져온 내용으로 교체됩니다.
- **가져오기 전 설정 복구:** 가장 최근 가져오기 직전의 원본 설정으로 되돌립니다. 사본은 이 브라우저의 PixAI 저장소에 보관하며 다음 가져오기 때 갱신됩니다. 브라우저 데이터를 지우면 없어지므로 장기 보관에는 JSON 내보내기를 사용하세요.

예전 **대기열 백업** 파일에서도 프리셋·캐릭터·청크·예약을 읽을 수 있습니다. 이때 기존 크레딧 상한·파일 이름·반복 횟수는 유지됩니다. 이미 등록된 생성 작업과 완료 이력은 가져오거나 재실행하지 않습니다. 현재 대기열은 그대로입니다. 저장 폴더 권한·다운로드 준비 상태와 패널 위치/접힘 상태는 해당 브라우저의 값을 사용합니다.

JSON은 최대5MiB까지 받습니다. 잘못된 파일은 적용하지 않습니다. 실행 중에는 불러오기를 막고, 저장 실패 시 원본으로 복원합니다. 새 기본 옵션은 입력값 변경 후 브라우저에도 저장됩니다.

## 저장 준비

브라우저가 지원하는 기능으로 저장 방식을 자동 선택합니다.

### Chrome / Edge 등

폴더 선택 API가 있으면 **저장 폴더 선택**을 눌러 에셋 폴더의 쓰기 권한을 허용합니다. 파일을 직접 저장하고 바이트 수를 확인합니다. 기존 파일은 덮어쓰지 않고 충돌 시 숫자를 붙입니다. 폴더 기록 실패 경고가 나오면 현재 탭에서만 사용하며 부분 저장 중 새로고침하지 마세요.

### Firefox 등

폴더 선택 API가 없으면 Tampermonkey의 **브라우저 자동 다운로드**를 사용합니다.

1. Firefox **설정 → 파일 및 애플리케이션 → 다운로드**에서 에셋 폴더를 정하고 매번 위치를 묻는 옵션을 끕니다.
2. 최신 Tampermonkey의 다운로드 모드를 **Browser API**로 설정하고 다운로드 권한을 허용합니다. 허용 확장자에 **png, jpg, webp, json**이 필요합니다.
3. PixAI 탭을 새로고침하고 **자동 다운로드 준비 확인**을 누릅니다. 작은 `PixAI_다운로드확인_시간.json`이 저장됩니다. 앱 이름·버전·확인 표시만 들어 있고 생성·크레딧 사용은 없습니다.
4. 확인 파일이 원하는 폴더에 저장됐는지 확인한 뒤 시작합니다. 준비 실패/취소/시간 초과이면 생성하지 않습니다.

브라우저가 사용하는 절대 경로는 스크립트에서 읽거나 보장할 수 없습니다. 실행 중 다운로드 위치를 바꾸지 마세요. 실제 파일명에는 브라우저가 충돌 숫자를 붙일 수 있습니다. JSON의 파일명은 요청 이름입니다. 다운로드 완료 알림을 확인하지만 저장 파일을 다시 읽지는 못합니다.

## 중지 · 복구

- 순서: 작업1회 제출 → 같은 작업ID로 완료 확인 → 원본 전부 저장 → JSON 기록 → 다음 작업.
- **중지**는 시작 준비·다음 제출·완료 확인을 멈춥니다. 서버에 이미 제출한 생성은 취소하지 않습니다. 실행 중 사이트를 직접 조작하면 중지합니다.
- 새로고침 뒤 자동 실행하지 않습니다. 폴더 선택 또는 다운로드 준비 확인 후 수동 재개합니다.
- 제출 결과가 불명확하면 자동 재제출하지 않습니다. 사이트에서 해당 작업을 확인하고 ID를 연결하거나 건너뜁니다. 제출 직전 검사에서 클릭하지 않은 것이 확실한 오류는 대기 상태로 남습니다.
- 저장 실패는 같은 작업ID로 재개합니다. 직접 폴더 저장은 동일 폴더를 확인하고 남은 이미지만 저장합니다. 자동 다운로드는 동일 경로를 확인할 수 없으므로 수동 재개 시 같은 작업의 원본 전부를 추가 사본으로 다운로드합니다. 두 방식 모두 재생성하지 않습니다.
- **대기열 백업**에는 작업과 프리셋 라이브러리가 함께 들어갑니다. 프롬프트는 해당 브라우저 프로필의 PixAI 사이트 저장소에 보관됩니다.
- 시작 설정이 부족하면 버튼 아래에 이유를 표시합니다. 0.1.6에서 준비 전 시작을 비활성화하던 경로는0.1.7부터 바꿨습니다. 실제 Firefox의 무반응 개선 여부는 사용자 화면에서 아직 확인하지 못했습니다.

## 지원 범위 · 제한

설정 프리셋의 범위는 **모델ID·버전ID와 LoRA 목록·버전·가중치·트리거 키워드**입니다. 트리거는 조합의 전송 프롬프트에 들어갑니다. **화면에 설정 적용 · 생성 안 함**은 모델·LoRA 설정만 적용하며 프롬프트는 시작 시 해당 작업의 조합으로 입력합니다. 해상도·이미지 수·CFG·샘플링 단계·기준 이미지 등은 프리셋에 포함하지 않습니다. 모델을 바꾸면 사이트가 다른 설정을 기본값으로 바꿀 수 있으므로 미리 적용해 확인하세요. 최종 표시 비용과 이미지 수는 제출 직전에 재검사합니다.

트리거 조회는 설정 읽기를 누를 때만 공개 PixAI 상세 페이지를 요청하며 로그인 쿠키·토큰을 보내지 않습니다. 선택된 LoRA의 ID/버전 URL을 요청하고 응답 주소와 모델 정보를 확인합니다. 상세 페이지의 **공개 Trigger Words**를 사용하며 버전별 전용 트리거 여부는 확인할 수 없습니다. 조회 중 사이트의 모델·LoRA·수치가 바뀌면 읽기를 중단합니다. 사이트 프롬프트 전체나 설명문에서 트리거를 추측하지 않습니다. 자동 읽기 뒤 프리셋을 저장하고 새로 예약한 조합에 반영되며, 이미 등록한 작업은 바뀌지 않습니다.

가중치 범위·간격은 사이트 입력창에서 확인합니다(확인한 DiT.3 모델은0~1.2/0.1, XL 모델은-2~2/0.1). 범위 밖 수치를 반올림하거나 조용히 바꾸지 않습니다. 비호환 LoRA 경고·다른 버전·추가 LoRA·수치 불일치가 있으면 제출을 막습니다. 모델 선택창에서 저장한 버전을 선택할 수 없으면 해당 버전을 사이트에서 먼저 선택해야 합니다. 특정 버전의 LoRA 자동 선택도 일치 확인 실패 시 멈춥니다.

네거티브 입력창이 없는 모델에서 네거티브 조합이 비어 있지 않으면 생성하지 않습니다. 지원 모델을 사용하거나 해당 조합의 공통/캐릭터/청크 네거티브를 비우세요.

생성은 사이트 버튼을 사용하고 완료·원본URL 조회는 사이트 내부 GraphQL을 사용합니다. 인증·응답 형식·원본 CDN/CORS·연속 실행은 아직 실검증 전이며 사이트 변경에 따라 깨질 수 있습니다. 쿠키·토큰·인증 헤더를 직접 읽거나 복사하지 않습니다. 같은 프로필의 다른 탭에서 수동 생성/설정 변경을 함께 하지 마세요. 대기열 중복 실행은 브라우저 잠금으로 막습니다.
